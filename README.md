# 슈퍼로봇대전 서바이브

슈퍼로봇대전 시리즈를 바탕으로 개인이 제작한 비공식 팬게임이다. 마징가 Z를 조작하며 중앙 연구소를 방어하는 2D 생존 액션으로, 자동 공격과 강화 선택으로 성장하고 15분 이후에는 무한 챌린지에 도전한다.

## 다운로드와 안내

- **[v1.1.0 배포 파일 받기](https://github.com/holizero/srw-survive/releases/tag/v1.1.0)**
- [게임 소개·다운로드·설치·전체 조작 안내](https://mntkim.com/srw-survive/)
- [English guide](https://mntkim.com/en/srw-survive/)
- [이전 v1.0.0 릴리스](https://github.com/holizero/srw-survive/releases/tag/v1.0.0)

설치 EXE와 배포 ZIP 중 하나를 받는다. ZIP에는 같은 설치 EXE·한글 설치 안내·EXE SHA-256이 들어 있으며 무설치판이 아니다. GitHub 자동 생성 Source code 압축 파일은 게임 설치 파일이 아니다. 각 다운로드의 무결성은 릴리스의 `.sha256` 파일로 확인한다.

## 패치 내역

v1.1.0은 로켓 펀치 100연발을 추가하고 연출을 개선한 업데이트다. **[상세 패치 내역은 블로그에서 확인한다.](https://mntkim.com/srw-survive-v1-1-0-update/)**

## 설치 전 확인

- Windows 64비트와 **Steam판 슈퍼로봇대전 V** 설치가 필요하다.
- 확인한 원작은 App ID `1031500`, 빌드 `4635641`이다. 다른 빌드는 지원을 보장하지 않으며 필수 파일이 다르면 설치 또는 실행이 중단될 수 있다.
- 배포 파일에는 원작 이미지·음성·음악·영상 에셋이 없다. 설치 도우미가 사용자 PC의 원작에서 필요한 자료를 읽어 구성한다.
- 설치 후에도 원작이 필요하다. 원작 파일과 세이브는 변경하지 않는다.

## 설치 방법

1. Steam에서 슈퍼로봇대전 V를 설치한다.
2. 설치 EXE를 실행한다. ZIP을 받은 경우 먼저 압축을 해제한다.
3. 원작 위치와 서바이브 설치 위치를 확인한다. 자동 검색에 실패하면 원작 폴더를 직접 선택한다.
4. **설치 시작**을 누르고 완료될 때까지 기다린다.
5. 바탕화면 또는 시작 메뉴의 **슈퍼로봇대전 서바이브**를 실행한다.

Windows의 **설치된 앱** 또는 설치 폴더의 **제거.exe**로 제거한다. 개인 최고 기록은 유지된다.

## 게임 특징

- 기체 생존과 중앙 연구소 방어를 함께 관리한다.
- 로켓 펀치·광자력 빔·루스트 허리케인·브레스트 파이어를 강화한다.
- 연구소 방어로 얻은 개발 포인트를 외벽·방어막·포대에 사용한다.
- 15분 이후에는 경험치와 추가 강화가 종료되고 점차 강해지는 적과 전투한다.
- 720p·1080p 출력과 창 모드·전체 화면, 오른쪽 무기 현황 패널을 지원한다.

## 안내

이 저장소는 설치판과 이용 안내를 제공하는 배포용 저장소다. 원작 파일과 에셋, 전체 개발 소스와 개인 검증 자료는 제공하지 않는다. 슈퍼로봇대전과 등장 작품·캐릭터의 권리는 각 권리자에게 있으며 본 프로젝트는 공식 제품이 아니다. 제삼자 구성 요소의 라이선스는 설치 폴더의 `resources/라이선스`에 포함된다.
