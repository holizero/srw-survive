# 슈퍼로봇대전 서바이브

그레이트 마징가와 플레이·음향 개선을 포함한 **v1.2.0** 배포판이다.

**[게임 소개·설치·이용 안내](https://mntkim.com/srw-survive/)** · [English guide](https://mntkim.com/en/srw-survive/)

[최신 v1.2.0 설치 파일](https://github.com/holizero/srw-survive/releases/tag/v1.2.0)

Windows 64비트와 Steam판 슈퍼로봇대전 V(App ID `1031500`, 지원 빌드 `4635641`)가 필요하다. 설치 후에도 원작이 필요하며, 원작 파일과 세이브는 변경하지 않는다. 원작 에셋은 배포 파일에 포함하지 않고 사용자 PC의 설치본에서 구성한다.

EXE와 ZIP 중 하나를 받는다. ZIP은 같은 설치 EXE·안내·체크섬 묶음이며 무설치판이 아니다. 자동 생성된 Source code 압축 파일은 게임 설치 파일이 아니다. 무결성은 릴리스의 `.sha256` 파일로 확인한다.

이 저장소는 배포 파일 보관용이다. 상세 설명은 블로그에서 제공한다. 비공식 팬게임이며 원작 및 등장 작품의 권리는 각 권리자에게 있다.
