# 슈퍼로봇대전 서바이브

마징가 Z를 조작하며 중앙 연구소를 지키는 비공식 팬 제작 2D 생존 액션 게임입니다. 자동 공격과 강화 선택으로 성장하고, 15분 방어 후에는 현재 장비로 무한 챌린지에 도전합니다.

## 다운로드

**[1.0.0 배포 파일 받기](https://github.com/holizero/srw-survive/releases/tag/v1.0.0)**

- 설치 EXE: 바로 실행하여 설치할 수 있습니다.
- 배포 ZIP: 같은 설치 EXE와 설치 안내, 설치 EXE의 SHA-256 파일을 묶었습니다. 별도의 무설치 실행판은 아닙니다.
- SHA-256: 내려받은 파일의 무결성을 확인할 수 있습니다.

## 설치 전 확인

- Windows 64비트 환경과 **Steam판 슈퍼로봇대전 V**가 필요합니다.
- 확인한 원작은 Steam App ID `1031500`, 빌드 `4635641`입니다. 다른 빌드는 지원을 보장하지 않으며 필요한 파일이 다르면 설치가 중단됩니다.
- 배포 파일에는 원작의 이미지·음성·음악·영상 에셋을 포함하지 않습니다. 설치 도우미가 사용자 PC의 원작에서 필요한 자료를 읽어 구성합니다.
- 설치 후에도 원작이 설치되어 있어야 실행됩니다. 원작 파일과 세이브는 변경하지 않습니다.

## 설치 방법

1. Steam에서 슈퍼로봇대전 V를 설치해 주세요.
2. 릴리스의 설치 EXE를 실행해 주세요. ZIP을 받으셨다면 먼저 압축을 풀어 주세요.
3. 설치 도우미에서 원작 위치와 서바이브 설치 위치를 확인해 주세요. 자동으로 찾지 못하면 원작 폴더를 직접 선택할 수 있습니다.
4. **설치 시작**을 누르고 완료될 때까지 기다려 주세요.
5. 바탕화면 또는 시작 메뉴의 **슈퍼로봇대전 서바이브**로 실행해 주세요.

제거할 때는 Windows의 **설치된 앱** 또는 설치 폴더의 **제거.exe**를 이용해 주세요. 개인 최고 기록은 유지됩니다.

## 게임 특징

- 중앙 연구소 방어와 기체 생존을 함께 관리합니다.
- 로켓 펀치·광자력 빔·루스트 허리케인·브레스트 파이어를 강화합니다.
- 연구소 방어로 얻은 개발 포인트를 외벽·방어막·포대에 사용합니다.
- 15분 이후에는 경험치와 추가 강화가 종료되고, 점점 강해지는 적을 상대로 생존 기록에 도전합니다.
- 720p·1080p 출력, 창 모드·전체 화면과 무기 현황 패널을 지원합니다.

|---|---|
| 이동 | WASD / 방향키 / 화면을 누른 채 드래그 |

| 게임 종료 | 상단 게임 종료 / Alt+F4 |

## 안내

이 저장소는 설치판과 이용 안내를 제공하는 배포용 저장소입니다. 원작 게임 파일이나 원작 에셋을 제공하지 않습니다. 슈퍼로봇대전 및 등장 작품·캐릭터의 권리는 각 권리자에게 있으며, 본 프로젝트는 공식 제품이 아닙니다. 제삼자 구성 요소의 라이선스는 설치 폴더의 `resources/라이선스`에서 확인할 수 있습니다.

관련 소식은 [Min IT 찍먹노트](https://mntkim.com/)에서 확인해 주세요.
